Student Course Registration System

A Python command-line application for managing students, courses, and course registrations. It includes duplicate checks, capacity rules, JSON storage, tests, and screenshots.

View on GitHub Run Locally

Features

Student Management

Add, view, and search students by ID or name with simple validation for required details.

Course Management

Add and view courses with trainer names, course IDs, and maximum registration capacity.

Registration Rules

Prevent duplicate registrations, invalid student or course IDs, and registrations into full courses.

Run Locally

This is a terminal Python project. Clone the repository and run it from your computer.

git clone git@github.com:brucemwendwa/Python-Module-Project-Exercise-Project-Title-Student-Course-Registration-System.git
cd Python-Module-Project-Exercise-Project-Title-Student-Course-Registration-System
python3 main.py

Tests

The project includes unit tests for duplicate students, duplicate courses, duplicate registrations, full courses, and JSON loading.

python3 -m unittest
